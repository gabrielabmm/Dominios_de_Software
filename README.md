# APS - Domínios de Software (2026/2)

Repositório oficial para a Atividade Prática Supervisionada (APS) da disciplina **Domínios de Software** do curso de Bacharelado em Engenharia de Software da Universidade Federal de Goiás (UFG).

## 📌 Sobre o Projeto
O objetivo deste projeto é o desenvolvimento de um documento técnico e arquitetural para uma aplicação Web focada estritamente no domínio de **Autenticação de Usuários**, compreendendo a recepção de credenciais, validação, comparação e decisão de autenticação.

## 👥 Equipe e Autoria
Conforme as diretrizes da disciplina, a autoria e a revisão dos artefatos estão distribuídas entre os membros da equipe para garantir a qualidade, integridade e conformidade com o princípio de "dividir e conquistar".
